# FYP - A Comparative Study of Python and Julia for Financial Analysis: Model Accuracy, Computational Efficiency and Scalability

This repository is part of an undergraduate final year research project. The study involves the comparison of Python and Julia over different method of financial analysis to try to determine which is better in terms of model accuracy, computational efficiency and sacalibility.

Our 4 Experiments are:
- Distribution fitting: modelling the financial returns
- Covariance and Correlation Matrix Analysis
- Portfolio Optimisation: using modern portfolio theory
- Monte Carlo Simulations
